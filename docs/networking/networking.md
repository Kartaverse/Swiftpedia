# Networking

## Overview

The Swift programming language allows you to access Apple's Swift and ObjectiveC based networking functions that are built ontop of macOS technologies. 

3rd party networking libraries like [Almofire](https://github.com/Alamofire/Alamofire) can make life easier if you are working with http based communication.

You also have the option of accessing the POSIX networking functions provided by the Darwin kernel's BSD/UNIX layer. This POSIX support is where termios communication happens with hardware like a USB serial port.
