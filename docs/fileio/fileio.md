# File IO

## Overview

The Swift programming language supports many native options for file I/O operations. You also have the ability to use FFI access to 3rd party libraries to add support for additional file types.

If you create software that interfaces with remote storage devices, it is possible to use Swift to create a "virtual file system". This allows your app to work similar to iCloud, or Google Drive where you have efortless cloud syncing of data in a low friction way.
