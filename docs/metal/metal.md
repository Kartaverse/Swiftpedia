## Overview

macOS uses the native Metal GPU API to provide direct access to the high-performance GPU accelerated graphics on Apple Silicon ARM64 systems.

If you use a graphics API like Vulkan on a macOS device, it is translated into Metal API based calls when the final rendering is performed.
