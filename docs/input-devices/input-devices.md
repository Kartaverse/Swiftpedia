# Input Devices

- Mouse
- Keyboards
- Gamepads
- SpaceMouse
- VRPN

## Overview

macOS supports a wide range of [HID](https://en.wikipedia.org/wiki/Human_interface_device) input devices. They are typically connected using USB, Bluetooth, or network interface.

Bluetooth devices like the [Sony DualSense](https://www.playstation.com/en-ca/accessories/dualsense-wireless-controller/) wireless controller can be used with macOS and iOS devices for precise game play control.

The [3Dconnexion SpaceMouse](https://3dconnexion.com/ca/) provides an effective way to navigate a 3D viewport for 3D design tasks like CAD an engineering.

[VRPN (Virtual Reality Peripheral Network)](https://github.com/vrpn/vrpn/wiki) is a network based communication system for interfacing VR focused input devices like camera trackers, hand tracker, and motion capture systems.
