# Xcode

## Overview

Developing applications with Swift typically involves a combination of the [Xcode](https://developer.apple.com/xcode/) IDE, the [xcode command-line build tools](https://developer.apple.com/documentation/xcode/installing-the-command-line-tools), [xcodegen](https://xcodegen.com/), [Homebrew](https://brew.sh/), and a git client like [GitHub Desktop](https://desktop.github.com/download/) or [GitKraken](GitKraken).

Something open-source developers have to deal with is that it is no longer feasible to try to distribute self-signed macOS applications in 2026. Having an Apple developer [code signing certificate](https://developer.apple.com/support/certificates) for code notarization really is a requirement for commercial application development with Swift and macOS Tahoe 26.5.
